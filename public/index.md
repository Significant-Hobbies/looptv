# LoopTV

A lean-back player that turns curated public YouTube channels into
television-style stations.

## How it works

- Pick a station or start one at random.
- LoopTV selects clips from a checked-in, periodically refreshed catalog.
- YouTube embeds provide playback; LoopTV needs no runtime API key.
- Watch history, saved videos, and preferences remain in browser storage.
